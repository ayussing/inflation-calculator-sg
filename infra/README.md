# Infrastructure (AWS CDK)

Deploys the unified Next.js app (`web/`) to AWS: ECS Fargate behind an ALB, a monthly scheduled
Fargate task for CPI ingestion, secrets in Secrets Manager, and CloudWatch alarms on an SNS topic.
Postgres itself is **not** provisioned here — the app connects to the already-provisioned Aiven
Postgres instance over the internet, so only its connection string is stored as a secret.

## Stacks

- `InflationCalculatorNetworkStack` — VPC (public + private subnets, 1 NAT gateway).
- `InflationCalculatorAppStack` — ECR image (built from `web/Dockerfile`), ECS cluster, Fargate
  service + ALB, Secrets Manager secrets, SNS alert topic, CloudWatch alarms.
- `InflationCalculatorIngestionStack` — scheduled Fargate task running `scripts/ingest-cpi.ts` from
  the same image, EventBridge schedule, ingestion-failure alarm.

## Prerequisites

- AWS CLI configured with credentials for the target account (`aws configure` or an SSO profile).
- Docker running locally (CDK builds `web/Dockerfile` and pushes it to ECR during deploy).
- Node.js 24+.

## First-time setup

```sh
cd infra
npm install
npx cdk bootstrap              # one-time per account/region
```

## Deploy

```sh
npx cdk deploy --all -c alertEmail=you@example.com
```

`alertEmail` is optional — omit it to skip the SNS email subscription. Region defaults to
`ap-southeast-1`; override with `CDK_DEFAULT_REGION`.

## After the first deploy

`DATABASE_URL` and `DATA_GOV_SG_API_KEY` are created as empty secrets (CDK can't know these — they're
Aiven/data.gov.sg credentials, not AWS-generated). Populate them once:

```sh
aws secretsmanager put-secret-value \
  --secret-id inflation-calculator/database-url \
  --secret-string "postgres://user:password@host:port/defaultdb?sslmode=require"

aws secretsmanager put-secret-value \
  --secret-id inflation-calculator/data-gov-sg-api-key \
  --secret-string "<your data.gov.sg API key>"
```

`inflation-calculator/ingest-secret` is auto-generated by CDK — nothing to do there.

Force a new deployment after updating a secret so the running tasks pick up the new value:

```sh
aws ecs update-service --cluster <cluster-name> --service <service-name> --force-new-deployment
```

The app's URL is printed as the `ServiceUrl` output of `InflationCalculatorAppStack` after deploy.

## Useful commands

- `npm run build` — type-check without emitting.
- `npx cdk diff` — preview changes against the deployed stacks.
- `npx cdk synth <StackName>` — print a stack's CloudFormation template.
- `npx cdk destroy --all` — tear everything down.
